Canvas First

The chart/report canvas takes most of the page, and chat becomes a collapsible command rail. Strong for finished dashboards, but it repeats the current problem of making AI feel secondary.

Implementation Scope I Recommend

Fixes

  • Projects: align dense folder cards, stop button wrapping/cropping, improve folder action hierarchy.
  • Upload: full-height file rail, no half-width centered/cut file area, stable independent scrolling.
  • Dashboard: remove inner Projects/Upload/Transform/Reports nav, make assistant and canvas the whole page.
  • Reports: remove tiny right chat, make report generation a full workbench with format controls and preview.

Visual System

  • Move away from heavy dark blue UI.
  • Use pearl/titanium surfaces, graphite text, champagne/rose/lavender accents.
  • Keep controls professional, dense enough for work, but not cramped.
  • Keep Transform mostly intact, only restyle enough to match the new system.
